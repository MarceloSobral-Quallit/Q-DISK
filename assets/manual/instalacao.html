Manual de Instalação do Q-DISK

Este manual mostra como conferir que o instalador é autêntico (assinado pela Quallit) e como instalar o Q-DISK. A instalação é feita só para o usuário atual, não pede senha de administrador e não exige instalar o .NET.

Sumário rápido

  • 1. Antes de instalar.
  • 2. Verificar o certificado do instalador.
  • 3. Aviso do Windows ao abrir o instalador.
  • 4. Instalar.
  • 5. Depois da instalação.

1. Antes de instalar

  • Windows de 64 bits.
  • O instalador Setup_qdisk_<versão>.exe, recebido da Quallit. O próprio Q-DISK baixa as atualizações de https://installer.quallit.com.br/qdisk/.
  • Não é preciso ser administrador do computador.

2. Verificar o certificado do instalador

Faça esta conferência antes de abrir o instalador. Ela garante que o arquivo foi publicado pela Quallit e não foi alterado depois.

Passo 1. Clique com o botão direito no arquivo do instalador, escolha Propriedades e abra a aba Assinaturas Digitais. Em Assinaturas Inseridas, o nome do signatário deve ser QUALLIT SERVICOS DE INFORMATICA LTDA. Selecione essa linha e clique em Detalhes.

Passo 2. A janela Detalhes de Assinatura Digital deve dizer "Esta assinatura digital é válida.", com o nome QUALLIT SERVICOS DE INFORMATICA LTDA. Em Referendas aparece o carimbo de data/hora da DigiCert. Clique em Exibir Certificado.

Passo 3. Na aba Geral do certificado, confira:

Emitido paraQUALLIT SERVICOS DE INFORMATICA LTDA
Emitido porDigiCert Trusted G4 Code Signing RSA4096 SHA384 2021 CA1
Válidode 22/10/2026 até 21/10/2027

Passo 4. Na aba Caminho de Certificação, a cadeia deve ser DigiCert → DigiCert Trusted Root G4 → DigiCert Trusted G4 Code Signing RSA4096 SHA384 2021 CA1 → QUALLIT SERVICOS DE INFORMATICA LTDA, e o Status do certificado deve dizer "Este certificado é válido."

Para uma conferência completa, a aba Detalhes do certificado mostra a Impressão digital, que deve ser 5d4730113cfc90891d3aec06630f53ee6df14b79.

Não instale se a aba Assinaturas Digitais não existir, se o signatário for outro, se a assinatura não for válida ou se o certificado estiver vencido. Apague o arquivo e peça um novo instalador à Quallit.

3. Aviso do Windows ao abrir o instalador

Ao abrir um instalador baixado da internet, o Windows pode mostrar a tela "O Windows protegeu o computador" (Microsoft Defender SmartScreen). Ela aparece com programas que o Windows ainda não conhece bem, mesmo quando estão assinados, como é o caso do certificado da Quallit, que é recente. Clique em Mais informações.

Confira o campo Fornecedor: ele deve trazer QUALLIT SERVICOS DE INFORMATICA LTDA. Só então clique em Executar assim mesmo.

Se o Fornecedor aparecer como desconhecido ou com outro nome, clique em Não executar e fale com a Quallit.

4. Instalar

Tarefas adicionais. Marque Criar ícone na Área de Trabalho se quiser um atalho na Área de Trabalho (o atalho no Menu Iniciar é criado sempre). Clique em Avançar.

Pronto para instalar. Clique em Instalar.

Instalando. Aguarde a barra de progresso. Se o Q-DISK estiver aberto, o instalador pede para fechá-lo antes de continuar.

Concluído. Com Iniciar o Q-DISK marcado, o programa abre ao clicar em Concluir.

5. Depois da instalação

  • O Q-DISK fica em %LOCALAPPDATA%\qdisk e no Menu Iniciar, na pasta Quallit.
  • Ao abrir, o programa pede o token de autenticação. O uso de cada tela está no Manual do Q-DISK, disponível no próprio programa (menu Manual).
  • As atualizações seguintes são oferecidas pelo próprio Q-DISK, que só aceita instaladores assinados pela Quallit.
  • Para desinstalar: Configurações → Aplicativos do Windows, item Q-DISK. As configurações e os logs do usuário são mantidos.
