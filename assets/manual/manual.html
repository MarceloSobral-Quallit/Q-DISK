Manual do Q-DISK

Este manual apresenta cada tela do sistema e como executar as principais tarefas. Antes de tudo, o programa exibe a tela de Autenticação (token). Depois de autenticado, use o menu lateral para navegar entre as telas: Inicio, Downloads, Copiar Backup TIBX, Gravar ISO Bootável, Teste de velocidade, Logs, Configurações, Sobre e Manual.

O botão Alterar Perfil, no canto superior direito de todas as telas, pede confirmação, fecha a tela principal e exibe novamente a tela de Autenticação para que outro token seja informado.

Sumário rápido

  • Entrar no aplicativo: tela Autenticação.
  • Fazer o download das imagens: tela Downloads.
  • Copiar TIBX para um pendrive: tela Copiar Backup TIBX.
  • Gerar USB bootável a partir de ISO: tela Gravar ISO Bootável.
  • Comparar desempenho dos links: tela Teste de velocidade.
  • Verificar log: tela Logs.
  • Ajustar configurações: tela Configurações.
  • Verificar informações do sistema: tela Sobre.
  • Acessar este manual: tela Manual.

1. Autenticação

Tela exibida ao abrir o aplicativo. Insira o token fornecido pelo Aplicativo do Técnico Quallit e clique em Validar para acessar o programa, ou em Sair para fechar o aplicativo.

Se o token estiver vazio, incompleto ou incorreto, o motivo aparece em vermelho abaixo do campo e também em uma janela de aviso.

Depois de 3 tokens incorretos seguidos, é preciso aguardar antes de tentar de novo: 30 segundos, e a espera dobra a cada novo erro, até 15 minutos. A espera continua valendo se o aplicativo for fechado e aberto de novo; um token correto zera a contagem.

2. Inicio

Tela exibida após a autenticação. Abaixo da imagem de abertura ficam atalhos para as tarefas mais usadas: Downloads, Copiar Backup TIBX e Gravar ISO Bootável, além dos botões Teste de velocidade, Configurações e Manual. Os atalhos abrem a mesma tela do menu lateral.

3. Downloads - baixar imagens

Esta tela permite buscar atualizações, selecionar imagens e fazer o download. Você também pode validar a integridade das imagens por hash e abrir a pasta dos arquivos ISO/TIBX.

  1. Clique em Atualizar para atualizar a lista.
  2. Marque a caixa da primeira coluna da grade na linha da imagem desejada (apenas uma imagem por vez).
  3. Clique em Baixar para iniciar o download.
  4. Use Cancelar para interromper um download em andamento.
  5. Use Validar integridade para conferir o hash da imagem.
  6. Use Abrir pasta para ver os arquivos baixados.

Ao parar o mouse sobre uma linha da grade, aparece a descrição da imagem e como gravá-la no pendrive (Como gravar).

Nas colunas Download e SHA-256, a legenda abaixo da grade indica: OK, Erro ou Não verificado (?). Ao abrir a tela o status ainda não foi verificado; clique em Atualizar para conferir as imagens locais.

4. Copiar Backup TIBX e Gravar ISO Bootável

As operações de pendrive agora ficam em duas telas separadas. Use Copiar Backup TIBX para copiar imagens TIBX e Gravar ISO Bootável para criar mídia de boot a partir de ISO. Gravar ISO, zerar o USB e formatar um pendrive exigem que o aplicativo esteja em Modo Administrador.

Se o aviso de administrador aparecer, clique em Ativar Modo Administrador. O Windows pede a confirmação de elevação e o aplicativo é reiniciado automaticamente já como administrador, sem precisar informar o token de novo. Quando o programa estiver sendo executado elevado, a mensagem Modo Administrador será exibida na barra de status inferior.

Sem o Modo Administrador ainda é possível:

  • atualizar a lista de USBs e selecionar imagens;
  • Copiar TIBX para USB, quando o pendrive já tem letra de unidade (um pendrive sem letra precisa ser formatado e exige o modo);
  • Verificar TIBX no USB e Imagem do USB;
  • Validar Boot do USB pelo manifesto; a verificação física (RAW/DD, MBR, partição ativa e setor de boot) exige o modo.

Copiar TIBX para USB e Gravar ISO Bootável ficam desabilitados até uma imagem ser selecionada na lista. Sem o Modo Administrador, Zerar USB fica desabilitado e, ao passar o mouse sobre ele, aparece a dica "Requer Modo Administrador.".

As imagens desta seção mostram as telas no estado padrão, sem o Modo Administrador ativo (aviso e botão Ativar Modo Administrador visíveis).

Ao selecionar uma imagem na lista, a tela mostra a descrição da imagem e Como gravar, definidos no catálogo, por exemplo "Como gravar: Cópia lógica FAT32 — Compatibilidade BIOS e UEFI". Quando o texto é longo, a caixa cresce e, se ainda assim não couber, aparece uma barra de rolagem. Uma imagem que não está nos catálogos aparece como "Imagem fora dos catalogos: sem descricao.".

Durante as operações, a linha de status abaixo da lista mostra a etapa em andamento e, quando é possível medir, o percentual real, também na barra de progresso (por exemplo "Copiando TIBX... 37%"). Isso vale para o cálculo de SHA-256, as cópias, a gravação RAW/DD e as verificações. Formatar o pendrive e analisar a ISO mostram só a barra animada. Mensagens longas quebram em mais de uma linha.

4.1 Copiar Backup TIBX

  1. Conecte o pendrive e clique em Atualizar USB.
  2. Selecione o USB no campo USB.
  3. Selecione a imagem na lista Imagens TIBX.
  4. Clique em Copiar TIBX para USB. Se o pendrive não estiver em NTFS, estiver gravado em RAW/DD ou tiver uma partição sem espaço para o arquivo, o aplicativo explica o motivo e pede confirmação para formatá-lo em NTFS, com o rótulo QDisk_TIBX. O NTFS é usado porque a mídia de boot Acronis restaura a partir dele (não restaura de exFAT, e o FAT32 não aceita arquivos acima de 4 GB).
  5. A cópia segue três etapas, com o percentual na linha de status:
    1. Validação do TIBX ("Validando SHA-256 do TIBX antes da cópia..."): o SHA-256 do arquivo baixado é comparado com o validado no download (ou, sem ele, com o do catálogo). Se não conferir, a cópia é cancelada e o aplicativo pede para baixar a imagem de novo na tela Downloads.
    2. Cópia ("Copiando TIBX...").
    3. Verificação no pendrive ("Verificando TIBX no USB..."): o arquivo copiado é comparado com o SHA-256 validado na primeira etapa. Ao final aparece "Verificação do SHA-256 do <arquivo> validado com sucesso." ou, se houver diferença, o aviso "SHA-256 divergente após cópia do TIBX.".
  6. Use Verificar TIBX no USB para conferir o hash do arquivo já copiado.
  7. Use Zerar USB somente quando precisar limpar o pendrive antes da cópia.

4.2 Gravar ISO Bootável

  1. Conecte o pendrive e clique em Atualizar USB.
  2. Selecione o USB no campo USB.
  3. Selecione a imagem ISO na lista Imagens ISO.
  4. Clique em Gravar ISO Bootável.
  5. Na janela Criar USB Bootavel, escolha o método: Boot BIOS, Boot UEFI, Boot RAW/DD ou Boot UEFI:NTFS. Para as imagens dos catálogos, o método vem definido pelo catálogo (o topo da janela informa) e só os métodos permitidos ficam habilitados; para as demais ISOs, vale a recomendação da análise da ISO. O método indicado já vem marcado. Clique em Continuar e confirme; o USB selecionado será formatado.
  6. O Boot UEFI:NTFS (usado na instalação do Windows 11) cria um pendrive que dá boot somente em PC com UEFI.
  7. Na cópia (BIOS, UEFI ou UEFI:NTFS), o pendrive recebe o rótulo definido no catálogo ou, sem ele, o rótulo da própria ISO. Em RAW/DD a imagem é copiada byte a byte e o pendrive fica com o rótulo que vem dentro dela.
  8. Ao final, o aplicativo confere a gravação: na cópia, a presença e o tamanho de cada arquivo e, com Validar hash após gravação do USB bootável ligado em Configurações, o hash de cada arquivo; em RAW/DD, com a mesma opção ligada, compara o pendrive com a imagem byte a byte.
  9. Use Imagem do USB para identificar qual catálogo/imagem já está gravado no pendrive, inclusive pendrives gravados em RAW/DD.
  10. Use Validar Boot do USB para conferir se o pendrive corresponde à ISO selecionada (manifesto, RAW/DD, boot).
  11. Use Zerar USB apenas quando a operação exigir limpeza do dispositivo.

Os botões Imagem do USB e Validar Boot do USB podem ser ocultados na tela Configurações; se estiverem desmarcados por lá, eles não aparecem nesta tela.

5. Teste de velocidade

Esta tela compara a velocidade dos links de download do Dropbox e do SharePoint. Cada origem é medida durante o tempo escolhido em Duração (10, 20, 30 ou 60 segundos), com 1, 4 e 8 conexões (marque em Conexões as quantidades a testar). Nada é gravado no disco. Por padrão, cada cartão usa o maior item daquela origem nos catálogos do seu perfil; você pode trocar o item na lista.

Clique em Iniciar. Durante a medição, o cartão mostra a velocidade do momento, a média, as conexões ativas e um gráfico com a velocidade de cada segundo; as barras Medição atual e Teste completo mostram quanto falta. Ao final, a tabela de cada cartão traz a média (MiB/s), o mínimo e o máximo, as conexões ativas e o tempo até o 1º byte para cada quantidade de conexões. A melhor quantidade aparece em verde e a origem mais rápida recebe o selo Melhor. O botão à direita das conexões exporta os resultados em CSV. O resultado é informativo.

6. Logs - verificar processos executados

Aqui você acompanha o histórico das operações realizadas pelo sistema, em uma tabela com as colunas Data e hora, Usuário, Versão e Evento. A entrada mais recente fica selecionada no fim da lista. Clique duas vezes em uma linha para ver o texto completo; ao parar o mouse sobre ela, o evento aparece em uma dica. Clique em Atualizar para recarregar o log.

7. Configurações - ajustes do programa

Defina comportamentos automáticos de validação por hash, pasta dos arquivos ISO/TIBX, limpeza de cache, limpeza de log e restauração de padrões. As opções ficam agrupadas nas seções Pasta dos arquivos ISO/TIBX, Atualizações, Validação de hash, Operações USB, Download e Manutenção.

  • Verificar atualizações de imagens na inicialização: ao abrir o aplicativo, atualiza os catálogos e avisa quais imagens já baixadas têm versão nova no catálogo, oferecendo abrir a tela Downloads para baixá-las de novo. Compara o hash registrado no download com o do catálogo, sem reler as imagens. Vem ligada, como a verificação de versão nova do aplicativo.
  • Validar hashes ao atualizar arquivos do cache: confere as imagens armazenadas localmente ao atualizar a lista.
  • Validar hash após download: valida a imagem assim que o download termina e salva o hash SHA-256 local.
  • Validar hash antes da gravação ISO: confirma a integridade da ISO antes de criar o USB bootável.
  • Validar hash após gravação do USB bootável: confere a mídia gravada quando a verificação estiver habilitada.
  • Validar hash após cópia TIBX: verifica o arquivo copiado no USB, comparando-o com o SHA-256 do TIBX validado antes da cópia (essa validação inicial é feita sempre).
  • Validar hash quando TIBX ja existir no USB: compara o arquivo existente com o TIBX validado antes de copiar novamente.
  • Desativar AutoPlay durante operações USB/ISO: evita que o Windows abra automaticamente o pendrive durante a operação.
  • Verificar atualizações do aplicativo na inicialização: avisa quando há uma nova versão do Q-DISK disponível ao abrir o programa. Use o botão Verificar atualização agora para checar manualmente.
  • Download multi-conexão (Dropbox e SharePoint): divide o download em várias conexões simultâneas para acelerar a transferência (ligada por padrão). Ajuste a quantidade em Conexões (2 a 8; padrão 8). No SharePoint, uma conexão que fica muito lenta é trocada automaticamente por outra, com ou sem esta opção.
  • Pasta dos arquivos ISO/TIBX: define onde os downloads e imagens locais serão armazenados. Use Procurar para escolher a pasta ou Padrão para voltar à pasta padrão (Downloads\qdisk do usuário).
  • Limpar cache de imagens: remove os arquivos salvos localmente e reinicia o status de download.
  • Limpar log: apaga o histórico de processos registrados pelo aplicativo.
  • Restaurar configurações: retorna todas as opções para o padrão de fábrica.
  • Exibir botão "Imagem do USB" e Exibir botão "Validar Boot do USB": controlam se esses dois botões aparecem na tela Gravar ISO Bootável.
